# ChiaFit Portugal

Versão da oferta do Método Chia destinada a Portugal, mantendo os textos em português brasileiro e publicada via GitHub Pages.

## Domínio

`metodochiapt.astroluz.site`

## Rotas

- Página principal: `/`
- Gummy: `/gummy/`
- Calistenia: `/calistenia/`

## Checkouts

Os checkouts dos planos Básico, Premium e Gummy estão configurados na Hotmart.
O checkout da Calistenia permanece temporariamente marcado como
`#checkout-pt-pendente` e deve ser substituído antes do lançamento.

## Desenvolvimento local

Sirva a pasta com qualquer servidor HTTP estático. Por exemplo:

```sh
python3 -m http.server 8080
```

Depois, acesse `http://localhost:8080`.
