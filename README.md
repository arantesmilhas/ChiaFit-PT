# ChiaFit Portugal

Versão da oferta do Método Chia destinada a Portugal, mantendo os textos em português brasileiro e publicada via GitHub Pages.

## Domínio

`metodochiapt.astroluz.site`

## Rotas

- Página principal: `/`
- Gummy: `/gummy/`
- Calistenia: `/calistenia/`

## Checkouts

Os checkouts dos planos Básico, Premium, Gummy e Calistenia estão configurados
na Hotmart.

## Desenvolvimento local

Sirva a pasta com qualquer servidor HTTP estático. Por exemplo:

```sh
python3 -m http.server 8080
```

Depois, acesse `http://localhost:8080`.
